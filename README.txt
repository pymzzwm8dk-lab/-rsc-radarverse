RSC RADARVERSE V3 — REVIEW PROTOTYPE

Open index.html in a browser, or deploy the contents of this folder to Cloudflare.
The logo is the exact transparent first image supplied by the user, kept at its natural 2:1 aspect ratio.
The UFO entrance is a simplified animated SVG layer; the logo image itself is unchanged.
Sections: Hero, Origin, Discover, Editorial filters, Awards voting demo, Contact.
Awards voting is a UI demo only and does not record real votes. All stories and editorial items are placeholders.
Instagram destination is placeholder until official handle is confirmed.

To update via GitHub: upload index.html and rsc-logo.webp to repository root and commit.
If Cloudflare is connected to main with automatic deployment enabled, the new build should publish after commit.
